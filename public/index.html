Kernel-based Root · GKI / LKM

把 Root
写进内核里

KernelSU 是基于 Linux 内核的 Android Root 方案:su 与权限管理运行在内核空间,OverlayFS 模块不碰系统分区,AppProfile 为每个 Root 应用做精细化控制。

为内核而生

不是给系统打补丁,而是把权限判断下沉到内核空间——从架构上做对 Root。

⚡

内核级权限管理

su 的授权判断发生在内核空间,用户空间的 Hook 与常见 Root 检测难以触及;应用只拿到被明确授予的最小权限。

🧩

OverlayFS 模块

模块经 OverlayFS 叠加生效,不修改 /system 分区,OTA 升级前一键停用即可恢复原状。

🛡

AppProfile

为每个 Root 应用单独配置 UID/GID、SELinux 上下文与 capabilities,授权精细到能力位。

📡

多种接入方式

GKI 设备可直接刷入官方内核镜像;支持以 LKM(可加载内核模块)方式运行,无需替换内核;非 GKI 设备可使用社区适配内核。

三步,完成接入

确认内核适配 → 刷入或加载 KernelSU → 安装管理器进行授权。
